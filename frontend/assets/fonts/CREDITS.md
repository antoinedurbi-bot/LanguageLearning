# Font credits

Fonts are bundled as static TTF files (rather than fetched at runtime via
`google_fonts`) so the app keeps working offline from first launch. All three
below are Google Fonts, downloaded from `fonts.googleapis.com` /
`fonts.gstatic.com` and committed here unmodified.

| Family | Files | Role |
| --- | --- | --- |
| Fredoka | Fredoka-500/600/700.ttf | Display, headings, buttons — the "Mimi" identity's rounded, warm face. |
| Nunito Sans | NunitoSans-400/600/700.ttf | Body text. |
| Space Mono | SpaceMono-400/700.ttf | Tags, stats, mono/tabular data. |

License: [SIL Open Font License 1.1](https://openfontlicense.org/) (OFL) for
all three families. The OFL permits bundling, embedding and redistribution
inside an application, including commercial use, without a separate license
grant, provided the font names are not used to promote a derivative build.
