# Sound effect credits

The WAV files in this directory are **not** sourced from a third-party
library. They are short sine/triangle-wave tones synthesized from scratch by
[`tools/build_sfx_assets.py`](../../../tools/build_sfx_assets.py).

## Why synthesized instead of a real CC0 library

The task called for genuinely free (CC0 or equivalent) recorded sound
effects, e.g. from freesound.org, as the preferred option. This sandbox's
egress proxy blocks connections to freesound.org and every other asset CDN
tried (`connect_rejected` — organization policy), so no external audio could
actually be downloaded or verified here. Rather than ship the app with no
sound at all, or fabricate a fake attribution for an asset that was never
really fetched, this script generates clean, tasteful, original tones
instead. This is honestly a lower-fidelity result than a proper SFX library —
a follow-up pass with real network access to freesound.org (filtered to CC0)
would be a straightforward improvement.

## License

Public domain / CC0 equivalent — these bytes are 100% generated by the
script above, not derived from any existing recording, so there is nothing to
attribute and no restriction on use.

## Files

| File | Used for |
| --- | --- |
| `correct.wav` | Correct answer (short ascending three-note chime) |
| `incorrect.wav` | Gentle/incorrect answer (soft two-note falling interval — never harsh) |
| `celebration.wav` | Streak / milestone / session-complete celebration (ascending arpeggio + held sparkle) |
| `tap.wav` | Low-stakes confirm/tap (single short quiet blip) |

Regenerate with `python3 tools/build_sfx_assets.py` from the repo root after
editing the script. Do not hand-edit the `.wav` files.
